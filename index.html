Platform safeguard

This block is specifically for the NT8 points-versus-dollars mistake.

Before every entry:
Write stop distance in points.
Then convert to dollars:
MNQ = $2 per point per contract, MYM = $0.50 per point per contract.
Then multiply by size:
Total risk = points × point value × contracts.
If that total exceeds planned loss:
reduce size, tighten stop, or skip the trade.
